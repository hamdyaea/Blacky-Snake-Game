# Blacky Snake

**Developer:** Hamdy Abou El Anein  
**Contact:** info@daylightlinux.ch  
**License:** GPL v3 (see LICENSE).

A modern Python 3/Pygame snake game with a testable, Pygame-independent grid engine. The game has collision handling, safe food placement, score display, adjustable speed and restart.

```sh
python3 -m pip install pygame
python3 Blacky-Snake-Game.py
python3 Blacky-Snake-Game.py --fps 18
python3 -m unittest discover -s tests -v
```

Controls: arrow keys or WASD to steer, R to restart after game over, Esc to quit. The original program is preserved on [old](https://github.com/hamdyaea/Blacky-Snake-Game/tree/old).
